# تجهيز برنامج فواتير المطبعة للنشر وتحويله إلى APK

## محتويات المجلد
- `index.html`: البرنامج الأصلي.
- `manifest.webmanifest`: تعريف التطبيق وأيقوناته.
- `sw.js`: ملف التشغيل الأساسي دون إنترنت بعد أول زيارة ناجحة.
- `icons/`: أيقونات التطبيق بمقاسي 192 و512.
- `.github/workflows/pages.yml`: إعداد نشر تلقائي على GitHub Pages.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات هذا المجلد كلها** إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح تبويب **Actions** وانتظر انتهاء مهمة `Deploy static PWA to GitHub Pages` بنجاح.
4. افتح **Settings → Pages** وتأكد أن النشر من GitHub Actions.
5. افتح رابط الموقع الذي يظهر في Pages من الهاتف، وانتظر تحميله مرة بالإنترنت.

## إنشاء APK
1. افتح موقع PWABuilder: https://www.pwabuilder.com/
2. الصق رابط GitHub Pages المنشور.
3. ابدأ الفحص، ثم اختر Package for Stores / Android.
4. اتبع خطوات إنشاء حزمة Android. احتفظ بملفات التوقيع ومفاتيح الإصدار في مكان آمن.

## ملاحظات مهمة
- يجب نشر الموقع على HTTPS حتى يعمل Service Worker ويمكن تثبيته كتطبيق.
- التشغيل دون إنترنت يعتمد على فتح التطبيق مرة واحدة بالإنترنت أولًا.
- البيانات الحالية تُحفظ محليًا في المتصفح/بيانات التطبيق. لا توجد مزامنة تلقائية بين أجهزة مختلفة في هذه النسخة.
- بيانات الدخول التجريبية ليست نظام حماية آمنًا؛ لا تستخدم هذه النسخة لحفظ بيانات حساسة أو لإدارة عدة موظفين عبر الإنترنت قبل ربط قاعدة بيانات ومصادقة آمنتين.
